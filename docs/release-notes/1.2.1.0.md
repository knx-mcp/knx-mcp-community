# KNX-MCP 1.2.1.0 — bug-fix release

**November 2026 · validated by KNX · available in the KNX Online Shop · currently free of charge**

**Official app distribution:** [KNX Online Shop (MyKNX product search)](https://my.knx.org/shop?action=search&search=KNX-MCP). This is a shop search link rather than a direct installer or product detail link.

This is a community documentation repository, **not a distribution repository for KNX-MCP binaries**. Any automatically generated GitHub “Source code” archives contain only this community repository, not an installable ETS App.

> **Program files signed through Microsoft:** the KNX-MCP program files now carry a code signature issued through Microsoft. ETS therefore loads the app on Windows 11 with **Smart App Control** switched on as well.

KNX-MCP 1.2.1.0 is a bug-fix release for 1.2.0.4. It contains the corrections from the feedback of users, testers and the community since Release 2. Operation, permissions and tools stay as in 1.2.0.4; settings are kept. The complete release notes in English and German are attached as PDF to the [GitHub release](https://github.com/knx-mcp/knx-mcp-community/releases/tag/app-v1.2.1.0).

## Signed program files

- The program files of KNX-MCP are signed with a code-signing certificate issued through Microsoft, with a timestamp, so the signature stays valid after the certificate expires.
- With Smart App Control switched on, Windows 11 only loads signed program files or files with a known reputation. Without a signature the app did not load in ETS ([#63](https://github.com/knx-mcp/knx-mcp-community/issues/63)).
- The signature of the ETS App package by the KNX Association is unchanged.

## Fixed issues

### Group addresses

- `ga_create`, `ga_copy`, `ga_create_range`: when the requested number was taken, ETS silently used the next free one. A warning now names the requested and the actual number; with `block` a gapless block is created or the call is refused.
- `ga_move` keeps the requested destination number when moving a middle group, and main groups can be renumbered ([#52](https://github.com/knx-mcp/knx-mcp-community/issues/52)).
- `ga_create_range` with `names`: each name gets the next number instead of being appended.

### Devices and parameters

- `device_set_parameter` checks a `device` given next to `parameter_id` – it must be in the project and own the parameter ([#58](https://github.com/knx-mcp/knx-mcp-community/issues/58)).
- `device_set_parameter`, `visible_changes`: a changed channel description no longer reports the channel's objects as gone and new.
- `device_get_options`: texts in the ETS language; filters find German and English texts.
- `device_update_objects`: datapoint type `9` and `9.*` count as the same main type.

### Building and functions

- `building_update_function` in ETS6: after removing an address the function is no longer reported empty; several removals in one call are carried out completely ([#53](https://github.com/knx-mcp/knx-mcp-community/issues/53)).
- The default group range of a function is read only – writing it led to an ETS error on undo in ETS6.

### Bus monitoring and bus status

- When the own bus monitoring falls silent, the telegrams of the ETS6 group monitor are taken over without duplicates.
- `bus_health` reports a silent connection (`stalled`, `no_data`) instead of staying `ok`.
- `ga_read_value` on addresses without linked objects no longer suggests a lost bus.

### Endpoint and panel

- The endpoint starts shortly after a project is opened, also when the KNX-MCP tab is in the background.
- ETS5: the panel no longer stays without texts after a full start.
- After an ETS restart the first change is no longer refused once with `PROJECT_RECHECK_REQUIRED`.
- MCP clients can end their session with HTTP `DELETE` as in the MCP specification.

### Project snapshot

- `project_create_snapshot`: on single ETS5 systems ETS showed the project empty after the export. The answer now reports `EXPORT_DAMAGED_PROJECT`: do not work on, close the project right away and open it again ([#60](https://github.com/knx-mcp/knx-mcp-community/issues/60)).

### DALI gateways

- `dali_get_config` also reads the DALI gateways of Schneider Electric SpaceLogic, MDT and GVS – read only ([#61](https://github.com/knx-mcp/knx-mcp-community/issues/61)).

## Compatibility

- Update over 1.2.0.4 without changes; settings, permissions and client configurations are kept.
- After the update, restart the AI client or start a new chat so it loads the tool list.

The complete product documentation and release material distributed with the app remain authoritative for the released package.
