**November 2026 · validated by KNX · available in the KNX Online Shop · currently free of charge**

**Official app distribution:** [KNX Online Shop (MyKNX product search)](https://my.knx.org/shop?action=search&search=KNX-MCP). This is a shop search link rather than a direct installer or product detail link.

KNX-MCP 1.2.1.0 is the third public release of the ETS App. It builds on Release 2 and brings the feedback of users and the community into the product. Operation, permissions and tools stay familiar; settings are kept. The complete release notes in English and German are attached as PDF to the [GitHub release](https://github.com/knx-mcp/knx-mcp-community/releases/tag/app-v1.2.1.0).

## Highlights

- **Signed program files:** signed through Microsoft – also for Windows 11 with Smart App Control ([#63](https://github.com/knx-mcp/knx-mcp-community/issues/63)).
- **Group addresses:** the assistant always knows the number ETS assigned; gapless blocks on request.
- **More DALI gateways:** Schneider Electric SpaceLogic, MDT and GVS can be read.
- **Bus monitoring:** seamless takeover of the ETS6 group monitor and a more precise bus status.
- **Endpoint:** available right after a project is opened.

## Signed program files

From 1.2.1.0 the program files of KNX-MCP are signed through Microsoft. ETS loads the app on Windows 11 with Smart App Control switched on as well and shows it in the app management as usual after installing.

## Refinements

### Group addresses

- `ga_create`, `ga_copy`, `ga_create_range`: when a requested number is already taken, the answer names the number ETS assigned; with `block` a gapless block is created, or the call names the numbers in use.
- `ga_move` keeps the requested destination number for middle groups and can renumber main groups ([#52](https://github.com/knx-mcp/knx-mcp-community/issues/52)).
- `ga_create_range` with `names`: each name gets its own consecutive number.

### Devices and parameters

- `device_set_parameter` checks that a `device` given next to `parameter_id` is in the project and owns the parameter ([#58](https://github.com/knx-mcp/knx-mcp-community/issues/58)).
- `device_set_parameter`, `visible_changes`: objects are compared by number and definition, so a new channel description shows exactly what changed.
- `device_get_options`: texts in the ETS language; filters find German and English texts.
- `device_update_objects`: datapoint type `9` and `9.*` are treated as the same main type.

### Building and functions

- `building_update_function` in ETS6: several addresses can be removed in one call, and the function shows its remaining addresses right away ([#53](https://github.com/knx-mcp/knx-mcp-community/issues/53)).
- The default group range of a function is shown read only, as ETS manages it.

### Bus monitoring and bus status

- When the own bus monitoring falls silent, KNX-MCP takes over the telegrams of the ETS6 group monitor without duplicates.
- `bus_health` also reports a silent connection (`stalled`, `no_data`), with a hint on free connections of the interface.
- `ga_read_value` on addresses without linked objects gives a clear answer about the bus state.

### Endpoint and panel

- The endpoint starts shortly after a project is opened, also when the KNX-MCP tab is in the background.
- ETS5: the panel checks its display after a full start and restores it when needed.
- After an ETS restart, a deliberate recheck of the project is enough before the first change.
- MCP clients can end their session with HTTP `DELETE` as in the MCP specification.

### Project snapshot

- `project_create_snapshot` checks the project after the export. On single ETS5 systems with certain other ETS Apps, the answer reports `EXPORT_DAMAGED_PROJECT` with clear guidance: close the project right away and open it again ([#60](https://github.com/knx-mcp/knx-mcp-community/issues/60)).

### DALI gateways

- `dali_get_config` also reads the DALI gateways of Schneider Electric SpaceLogic, MDT and GVS – read only ([#61](https://github.com/knx-mcp/knx-mcp-community/issues/61)).

## Compatibility

- Update over 1.2.0.4 without changes; settings, permissions and client configurations are kept.
- Tool names and parameters stay the same; new fields in the answers are additional.
- After the update, restart the AI client or start a new chat so it loads the tool list.

The complete product documentation and release material distributed with the app remain authoritative for the released package.
