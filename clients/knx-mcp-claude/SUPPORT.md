- Setup/questions: https://github.com/knx-mcp/knx-mcp-community/discussions

- Security: report privately to support@knx-mcp.com, subject **KNX-MCP security**,
  or use the community's private vulnerability reporting.

Include client version/build date/source fingerprint, Claude and Windows
versions, relevant ETS/App versions, connection method, sanitized codes and steps.
Do not publish full status if names or server instructions identify a customer.
Never include access keys, profiles, private keys, ETS projects, KNX Secure secrets
or unredacted customer logs. Reports are not submitted automatically.
